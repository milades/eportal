# چرخه عمر فازها

## وضعیت‌ها

    Draft
      -> Awaiting Owner Approval
      -> Approved
      -> In Progress
      -> Review
      -> Accepted

در هر وضعیت امکان ثبت <code>Blocked</code> وجود دارد. رفع Blocker، وضعیت را
به آخرین مرحله معتبر بازمی‌گرداند و به‌خودی‌خود مجوز عبور از Gate نیست.

## اختیارات

عامل هوش مصنوعی می‌تواند وضعیت‌های Draft، In Progress، Review و Blocked را
با شاهد پیشنهاد یا ثبت کند. فقط مالک پروژه مجاز است:

- فاز را Approved یا Accepted اعلام کند؛
- فاز فعال را تغییر دهد؛
- Scope Baseline را تصویب یا اصلاح کند؛
- ریسک‌های خارج از محدوده را بپذیرد؛
- تغییر واقعی زیرساخت، commit، push، PR، merge یا deploy را مجاز کند.

## مرجع تأیید

هر تأیید باید دارای شناسه‌ای مانند <code>APP-P0.1-001</code> باشد و این
اطلاعات را ثبت کند:

- تصمیم دقیق؛
- نسخه یا SHA-256 سند مورد تأیید؛
- نام یا نقش تأییدکننده؛
- تاریخ؛
- شروط یا استثناها؛
- محل شاهد تصمیم.

عبارت مبهم، سکوت، ادامه گفت‌وگو یا انجام کار قبلی جایگزین تأیید صریح نیست.
