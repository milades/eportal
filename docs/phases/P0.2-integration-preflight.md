## هدف

همه Placeholderهای معماری با مقادیر واقعی و دارای مالک جایگزین شوند؛ یک
محیط Integration مجزا روی همان Windows Server آماده شود؛ آمادگی AD، DNS،
TLS، gMSA، SPN، IIS، SQL Server و Chrome GPO با Preflight اثبات شود؛ و
Kerberos واقعی همراه با رد NTLM توسط Probe موقت تأیید گردد.

## خروجی Gate

- Integration FQDN، Site، App Pool، gMSA، SPN و Database جدا؛
- Parameter Inventory واقعی، کامل و بدون Placeholder در storage کنترل‌شده
  خارج از Git، همراه با manifest پاک‌سازی‌شده داخل Repository؛
- Preflight نهایی بدون خطای حل‌نشده؛
- ورود Kerberos آزمایشی و تست منفی NTLM؛
- Snapshot، Rollback و Evidence کامل؛
- تأیید انسانی مسئولان مربوط.

## Preflight اجباری

1. Domain Join و Secure Channel سرور و کلاینت پایلوت؛
2. A Record مستقیم، Forward/Reverse resolution و همگامی ساعت؛
3. KDS Root Key و امکان نصب gMSA؛
4. نبود SPN تکراری؛
5. Trust Chain و SAN صحیح TLS؛
6. نصب IIS پیش از Hosting Bundle یا Repair آن؛
7. Windows Authentication Role Service؛
8. App Pool x64، In-Process، No Managed Code، AlwaysRunning و Idle صفر؛
9. preloadEnabled و Identity صحیح Integration gMSA؛
10. ACL حداقلی gMSA برای SQL، پوشه، Registry و Private Key و تأیید اینکه
    gMSA روی Trusted for Delegation قرار ندارد؛
11. تنظیم <code>useKernelMode=true</code>،
    <code>useAppPoolCredentials=true</code> و Windows Authentication provider
    فقط برابر Negotiate؛
12. آزمون Extended Protection ابتدا روی Allow و سپس، در صورت سازگاری، روی
    Require؛ نتیجه و علت تصمیم نهایی ثبت شود؛
13. SQL با پروتکل و hostname واقعی مصوب، تطابق SAN، Trust Chain معتبر،
    <code>Encrypt=True</code> و <code>TrustServerCertificate=False</code>؛
14. Chrome ADMX/ADML و Machine Policy؛
15. AuthServerAllowlist دقیق و Status=OK در chrome://policy؛
16. Impact Assessment مسدودسازی NTLM روی سرور مشترک؛ ناتوانی در مسدودسازی
    قابل اثبات NTLM بدون آسیب به سرویس‌های دیگر، نتیجه <code>BLOCKED</code>
    است و Warning قابل پذیرش نیست؛
17. نبود Password، Secret، Private Key و topology واقعی در
    parameter/artifact/evidence داخل Git؛
18. جدایی Integration از Production شامل Site، App Pool، FQDN، Binding،
    Certificate، SPN، gMSA، Database، Migration History، Cookie Host/Prefix،
    دسترسی فقط تیم پروژه و سیاست Stop/Disabled شدن App Pool پس از Go-Live؛
19. حساب‌های تست Valid، Disabled، Locked، Account Expired،
    Password Expired، Must Change Password و Rename.
