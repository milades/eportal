# Architecture Decision Records

تصمیم‌های معماری مصوب نقشه راه در فاز P0.1 خط مبنا می‌شوند. هر تغییر مهم
بعدی باید در یک فایل مستقل با الگوی زیر ثبت شود:

    ADR-NNN-title.md

    Status: Proposed | Accepted | Superseded | Rejected
    Context:
    Decision:
    Alternatives:
    Security and operational consequences:
    Verification:
    Rollback or migration:
    Approval reference:

ADR پیشنهادی تا زمان تأیید مالک، مجوز پیاده‌سازی ایجاد نمی‌کند.
